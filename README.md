# K9Bits

K9Bits is a small neural network that maps a fixed-size 144x256 grayscale image to a 64-bit integer.

Training is done with a Python script using NumPy. The trained weights are exported to a C header file. Inference is implemented in C and can be compiled without Python.

The project is intentionally limited. It does not decode image formats, resize images, or handle arbitrary input sizes. It expects raw grayscale bytes.

## Files

train.py — trains the model and generates weights.h  
nn.h — C API declaration  
nn.c — C inference implementation  
main.c — small command-line test program  
weights.h — generated by train.py, not stored in the repository by default

## Dataset format

The training file is a binary sequence of records.

Each record contains:

```text
144 * 256 bytes   image pixels, 8-bit grayscale, row-major
8 bytes           uint64 label, little-endian
```

Total record size: 36872 bytes.

Example layout:

```text
[image 0][label 0][image 1][label 1][image 2][label 2]...
```

The training script ignores incomplete trailing bytes.

## Training

Requires Python 3 and NumPy.

Basic usage:

```sh
python train.py dataset.bin
```

With a custom number of epochs:

```sh
python train.py dataset.bin 300
```

The default number of epochs is 300.

After training, the script writes `weights.h`. This file contains `NN_HID` and the trained weight arrays.

Training prints exact-match accuracy. An example is counted as correct only if all 64 predicted bits match the 64-bit label.

The script loads the whole dataset into memory.

## Building the C test program

After training, make sure `weights.h` is in the same directory as the source files.

Build:

```sh
cc -O2 -o nn_test main.c nn.c
```

Run:

```sh
./nn_test image.raw
```

`image.raw` must contain exactly 36864 bytes: the raw 144x256 grayscale image.

If no file name is given, the program reads from stdin.

The output is the predicted 64-bit value printed as an unsigned decimal integer.

## Using the C API

```c
#include "nn.h"

uint64_t value = nn_predict(img);
```

`img` must point to 144 * 256 bytes of grayscale pixel data.

`nn_predict` returns a `uint64_t`. Bit 0 corresponds to the least significant output bit.

The inference function uses local arrays and generated constant weights. It does not call `malloc` and does not use global mutable state. The test program `main.c` uses stdio, but `nn_predict` itself is designed to be easy to embed.

## Network structure

The network is fixed:

1. Input image: 144x256 uint8 grayscale.
2. Average pooling with 8x8 blocks.
3. Pooled feature map size: 18x32 = 576 values.
4. Dense layer: 576 inputs to `NN_HID` hidden units, ReLU activation.
5. Dense layer: `NN_HID` inputs to 64 outputs.
6. Threshold: output bit is 1 if the corresponding logit is greater than 0.

`NN_HID` is set in `train.py`. The default value is 32. Increasing it may improve capacity but also increases code size and memory use.

## Notes and limitations

- Input size is fixed at 144x256.
- Input must be raw grayscale bytes.
- The dataset must already be prepared in the binary format described above.
- The training script reports training accuracy only.
- There is no built-in validation split.
- Exact 64-bit match accuracy can be much stricter than per-bit accuracy.
- The C code requires floating-point support.
- Changing `NN_HID` requires retraining and rebuilding the C code.
